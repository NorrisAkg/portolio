Write a new Architecture Decision Record following the project's
ADR format defined in `.claude/rules/adr-format.md`.

## Process

1. Read `.claude/rules/adr-format.md` to refresh the format
2. Read `docs/adr/README.md` to find the next ADR number
3. Ask me:
   - The title of the decision (short, descriptive)
   - The status (typically "Accepted" for new ADRs)
   - A summary of the context, decision, and alternatives I've
     considered
4. Draft the ADR in `docs/adr/NNNN-kebab-case-title.md` using the
   template
5. Update `docs/adr/README.md` to add the new entry to the index
6. Show me the draft and ask for any revisions

## Reminders

- Keep it short (1 page max)
- Be honest about negative consequences — every choice has trade-offs
- List 2-3 alternatives minimum
- Use sentence case in headers, not Title Case
- Don't add fluff to fill space; if you're padding, the ADR is done
